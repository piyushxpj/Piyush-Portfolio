# How It Works

_Last updated: 2026-10-07_

## Production hosting

Vercel project `piyush-portfolio` tracks `codex/figma-hero` for Production, with automatic assignment to the existing `piyushjain.in` and `www.piyushjain.in` domains. Pushes to this branch publish the new portfolio. `main` is deliberately preserved at `56433b69fdd3b3f19fab79ce6aa30cc1b1280ae3` with the original Figma-style portfolio; do not merge or overwrite it as part of new-design releases. To restore the old site, change Production branch tracking to `main` and deploy that branch (changing tracking alone does not replace the active deployment). The previous production deployment is `54fwgh141oJdQuBeEdcWrDxVkbGQ`.

The Experiments placeholder uses Hero Roobert sans-serif with an inline transparent icon sized to 1.2em tall.

Piyush Jain's portfolio is a React 18 application served by Vite. `App.jsx` owns navigation, theme state, responsive shells, and project modals. `/` renders `HeroSectionV2.jsx`, styled in `hero-v2.css` with shared stamp and font styles from `hero.css`, outside the old canvas. `/work` shares this stamp shell and renders `WorkPage.jsx` as a scrolling gallery; `/about` renders `AboutPage.jsx` as a readable story. `/playground` renders a centered “Experiments coming soon” state within the same stamp shell. `PlaygroundPage.jsx` uses `public/experiments-icon-transparent.png` and `experiments-page.css`: the background-extracted icon is text-height and inline with a single-line heading, with shared responsive sizing from 18px to 36px. No gallery images or videos mount there. The original supplied icon, `public/playground/` media, and manifest remain available; Work references three of the original gallery assets. Builds retains the legacy canvas/mobile shell.

## Preserved Hero V1 implementation

The following notes describe the retained, unmounted V1, not the active homepage.

The hero matches Figma file `bCf51Jh7ebnEUdQ3Pyn4th`, node `1025:1136` (1280 × 832). Its wrapper fills `100svh`; proportional desktop positioning preserves the reference geometry. Below 768px the same assets and copy reflow; a minimum 800px composition can scroll on short phones. The portrait remains two image layers, the birds and client marks use individual exports, and the background pattern is clipped by the responsive stamp mask. It is not a flattened screenshot of the design.

The stamp uses four intersected, repeating radial-gradient masks rather than stretching the original whole-frame SVG. Cutouts keep an 8px circular radius (6px below 768px); rounded repetition distributes whole tiles along each edge without clipped corner motifs. The original textured paper image is oversized by 3% on each side, hiding its baked-in perforations. Mobile portrait width is also capped by the vertical room above the client logos, with its sun tile and bird anchored to the same width.

The homepage contains only the viewport-height stamp hero against #252525. The project placeholders and their scrolling continuation have been removed. Normal desktop and tall-phone views have no extra scroll; the original minimum-height fallback still allows the hero to remain accessible on short screens rather than clipping content. The sound toggle remains fixed at bottom right.

The hero navigation lists About, Work, Playground, and Case Study. About links to the current introduction at `/`; Work and Case Study link to the existing work collection at `/?section=work`. Builds remains accessible at `/?section=builds`; Playground uses `/playground`. Desktop hover and keyboard focus turn links ocean blue, roll individual letters upward one line in 240ms with an 18ms stagger, and reveal a decorative arrow in 150ms without shifting the hit area. Each letter has a clipped duplicate; the visual label is hidden from assistive technology and the native link retains a single full accessible name. Interruptible CSS transitions return all letters together in 150ms on exit. Reduced-motion uses the color and arrow without movement; the mobile row keeps text static and omits arrows to keep four 44px-high targets clear. History and reloads restore the selected section. Contact is a mail link to the existing portfolio email. No separate case-study landing page was invented.

The blue band retains `public/hero/blue-pattern.svg` from Figma node `1021:8644` (1240 × 253) as its source. The full export is not horizontally seamless: its outer edges cut motifs, and duplicated internal arch blocks overlap unevenly. Eight derived `pattern-row-*.svg` tiles reuse original path data inside clean, matching motif boundaries, with row boundaries at 0, 33, 50, 99, 140, 178, 193, 210, and 253. Each row repeats its own complete motif and translates exactly one tile width per loop. Duration is `60 × tileWidth / 1240` seconds, preserving the previous visual speed. Adjacent rows alternate left/right, and an oversized track keeps both edges covered. The tracks stay clipped inside the stamp mask and preserve aspect ratio on desktop/mobile. Only transforms animate, with no React state or per-frame JavaScript. The motion button remains removed at the user's request. With `prefers-reduced-motion: reduce`, all rows stay static.

The animated band uses four uninterrupted, equal-height palette sections in order: purple/lilac (source rows 0/33), blue/yellow (50/99), coral/pink (140/178), and green/yellow (193/210). Each occupies 25% of the band. `patternGroups` scales both height and tile width proportionally within each section, preserving motif geometry and seamless boundaries; duration uses the scaled width to retain travel speed. `sourceStart` remains the original asset identifier while `start` is its normalized display position. The original blue Figma export is retained as source. The navigation accent, sun tile, and ship artwork are unchanged.

Project data lives in `canvasData.js`; media is served from `public/`. `styles.css` contains shared styles. `api/github-contributions.js` requests GitHub's GraphQL contribution calendar server-side using `GITHUB_TOKEN`; `vite.config.js` provides the matching local endpoint. Never expose that token in client code.

The yellow tile retains its original circles at rest. Fine-pointer hover runs staggered circle pops on a 1.2-second CSS loop (40% contraction, 118% overshoot, then settling). The square stays fixed and the SVG viewport clips the animation. Pointer exit restores the original circles. Reduced-motion and touch-only devices keep the artwork static.

All four decorative hero birds follow short, curved out-and-back flight paths around their original positions on independent 18–22-second loops. CSS translate moves each wrapper without overwriting its original rotation. Mobile uses smaller 12–20px horizontal routes to stay inside the composition. Three clipped copies of each unchanged SVG isolate the left wing, rigid body, and right wing. Opposing 14–16-degree skew transforms hinge at the clip boundaries, keeping shoulders connected. Independent 2.6–3.2-second wing loops continue during travel; reduced-motion disables both travel and flapping entirely.

Run `npm install`, then `npm run dev`. Validate production output with `npm run build`. Vercel routing is configured in `vercel.json`, including `/cv` and `/playground`.

`HeroAmbience.jsx` owns the homepage-only audio element and fixed bottom-right sound toggle. `/hero/beach-with-birds.mp3` preloads and attempts automatic looping playback at 60% volume on mount. The supplied beach recording remains untouched; `node scripts/mix-hero-ambience.mjs` uses FFmpeg to mix filtered, softly faded CC0 bird excerpts into a separate 224.376-second MP3. The first call starts at 2 seconds, then calls occur at irregular 8–12-second start intervals. A single mixed track keeps both layers synchronized with mute, looping, and route cleanup; there are no runtime scheduling timers. The bird source and license are recorded in `public/hero/ASSETS.md`. Rendering writes a temporary file then renames it to avoid serving partial audio.

If the browser blocks autoplay, pointer-down, pointer-up (for touch activation), or keyboard interaction retries playback. Manual mute cancels these retries, so later gestures cannot override the visitor's choice. A 32px visible control has a 44px button target, keyboard focus and `aria-pressed` state. Real playback failures announce a retry message; an autoplay-policy rejection is handled silently. Unmount removes gesture listeners, pauses audio, and invalidates pending play requests. Returning home attempts autoplay again. The recording has no silent lead-in; observed startup delay was an autoplay rejection despite readyState 4 and buffered media, not an intentional timer.

The generated transparent `public/hero/sailboat-v2.png` sits inside the blue pattern's clipped container, behind foreground content. Its folk-print charcoal hull, cream sails, blue geometric marks, and yellow pennant echo the hero assets. A full-width crossing wrapper translates from entirely off the left edge to beyond the right edge over 75 seconds (48 on mobile), with a negative phase so it starts visible. A nested wrapper independently bobs ±3 design pixels and rolls ±3 degrees over 4.8 seconds. Both loops animate transforms only; reduced-motion leaves a visible, stationary boat. The source image and generation prompt are documented in `public/hero/ASSETS.md`.

The sound toggle represents the enabled preference (on by default), not autoplay permission. A browser autoplay rejection keeps the unmuted icon and enabled state, with a waiting tooltip; a real media error switches it off. Manual mute still cancels pending playback retries.

The hero fonts in `public/fonts/` are the locally installed trial versions used in Figma. Replace them with properly licensed webfonts before publishing. The new homepage does not request GitHub data; the retained canvas still needs a valid server-side `GITHUB_TOKEN` for contributions.
